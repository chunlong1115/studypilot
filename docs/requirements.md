# StudyPilot 需求规格说明

## 项目背景

大学生在学习过程中常遇到：资料太多整理困难、不知道重点、复习效率低、缺少个性化规划、错题无法系统管理。

## 核心功能

### 1. 用户管理
- 用户注册（邮箱验证）
- 用户登录 / 登出
- 找回密码（邮箱重置链接）
- 修改个人信息（用户名、邮箱、头像）
- 学习偏好设置（学科方向、学习目标、难度偏好、每日学习时长）

### 2. 学习资料管理
- 上传 PDF 文件并自动解析文本
- 创建 / 编辑纯文本笔记
- 上传图片（拍照笔记）
- 保存网页链接
- 资料列表、查看、删除

### 3. AI 智能总结
- 基于 DeepSeek API 对资料内容进行自动总结
- 提取关键知识点

### 4. AI 智能出题
- 基于学习资料自动生成题目
- 题型：选择题、填空题、简答题、判断题

### 5. 错题管理
- 答题后自动收录错题
- 间隔重复复习算法
- 错题复习模式

### 6. 学习进度分析
- 学习时长统计
- 答题正确率趋势
- 错题解决率

### 7. 智能复习提醒
- 站内消息提醒
- 待复习错题提醒
- 每日学习目标提醒

## 目标用户

多用户平台，面向大学生群体。

## UI 要求
- 简洁、直观
- 主色调：淡蓝色 (#4A90D9)
- 全中文界面
- 响应式布局（桌面 + 平板优先）
