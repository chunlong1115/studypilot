# StudyPilot UI 设计规范

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色 | `#4A90D9` | 淡蓝色，用于导航栏、主按钮、链接 |
| 主色深 | `#357ABD` | 按钮 hover 状态 |
| 主色浅 | `#6BA5E7` | 输入框 focus 边框 |
| 主色背景 | `#EBF2FA` | 浅蓝背景色 |
| 页面背景 | `#F5F7FA` | 浅灰背景 |
| 文字主色 | `#333333` | 正文内容 |
| 文字次色 | `#777777` | 辅助说明文字 |
| 卡片背景 | `#FFFFFF` | 白色卡片 |
| 边框色 | `#E4E8EC` | 分割线、边框 |

## 字体

```
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
             "PingFang SC", "Microsoft YaHei",
             "Helvetica Neue", Arial, sans-serif;
```

- 中文字体优先：苹方 → 微软雅黑
- 英文字体优先：系统原生字体

## 布局规范

- 容器最大宽度：Bootstrap `container`（1140px at lg）
- 卡片圆角：12px
- 按钮样式：Bootstrap 原生 + 自定义颜色
- 间距：使用 Bootstrap spacing 工具类 (mt-4, mb-3, g-4 等)
- 导航栏：固定顶部，淡蓝色背景，白色文字

## 组件风格

- **卡片**: 白色背景，浅阴影 (`shadow-sm`)，hover 时轻微上移
- **按钮**: 圆角，主按钮淡蓝色填充，次按钮描边
- **表单**: focus 时淡蓝色边框阴影
- **提示框**: 无边框，圆角 8px

## 图标

使用 Bootstrap Icons (CDN)，导航栏和卡片中均使用图标辅助表达。

## 响应式断点

| 断点 | 宽度 | 布局 |
|------|------|------|
| 手机 | < 768px | 单列 |
| 平板 | 768px - 991px | 双列 |
| 桌面 | ≥ 992px | 多列网格 |
